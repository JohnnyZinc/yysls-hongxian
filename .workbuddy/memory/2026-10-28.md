## 转律建议必须全局感知（用户提出，已原型验证）
- **根本边界：等阶是部位级判定（局部），配额是全局约束（8 部位 40 条）。局部天档 ≠ 全局适配。**
  例：鸣金虹剑 大外/大外/剑增/劲/势 → 局部仍判**天**，但若全局会意率缺 1、劲溢出 1，则转「劲→会意率」更好。
  ⇒ 面板应写："天档。但转律「劲」→「会意率」可满足全局配额。"
- **判定标准 = 全局缺口最小化**：用 `monitor.js quotaCensus(gear, flow, aliasMap)` 算全套装备 vs 配额的缺口，枚举 (调律位 × 转律池目标) 取缺口最小者。引擎现成，无需新算法。
- 实测三场景（鸣金虹·大外流，solveAssignment 造基准后扰动）：
  - A 单缺（会意缺1 + 劲溢出1）→ 唯一解 劲→会意率，缺口 1→0 ✓
  - B 双缺（会意缺1 + 势缺1 + 劲溢出2）→ 劲→势 与 劲→会意率 **并列**（2→1），⚠ 需次级标准
  - C 拆东墙（缺会意但劲/势无溢出）→ 转任何一条都产生新缺口，缺口 1→1 **无收益 ⇒ 不建议转**
- **【已定 2026-10-28】转律建议规则**：
  1. 方向 = **全局配额缺口最小化**；
  2. **唯一解** → 直接给；
  3. **多缺口并列** → 用 **DPS 决胜**（消灭哪个缺口提升的 DPS 更高就转哪个）；
  4. **原词条无溢出、转律只是拆东墙补西墙** → **不建议转，即使转律后 DPS 更高也不建议**（用户拍板）；
  5. **结构型（玄/黄→天）必给；优化型（天→天但全局更适配）也给**。
- **为什么决胜用 DPS 而不是三率达标（用户问过）**：
  - 三率**上限**（游戏硬截断）**已在 DPS 里 clamp**（dps.js `Math.min(CAPS['黄字会心率上限'], …)`）⇒ DPS 自动识别"超上限=0收益"；
  - 三率**达标线**（thresholds）是作者期望值，**不进 DPS**，且是二值（达/未达）无法比较"达哪个更好"，也不含势/劲/攻击/增伤的贡献；
  - ⇒ 决胜用 DPS；**三率达标降级为文案辅助**（"转成会意率还能让会意率达到期望的 40%"）。
- 性能：calcDPS 实测 **0.81ms/次**；策略 = 两阶段：先用缺口筛出并列最优（通常 1~3 个），只对这几个算 DPS（勿对全部 ~60 候选都算）。
- ⚠ 坑：两候选 DPS 差若落进 swap deadZone ⇒ 实际等价，应并列列出或按转律成本/保留神力决定。
- 接口影响：现 `gradeItem` 是纯单件（不知其他部位）。做全局感知须把"当前整套装备"传入 —— 接口级改动。
- ⚠ 更深层：全局最优可能需多件同时转律（单件看无收益，两件一起有收益）= 组合优化。先做单件贪心，是否升级待定。
