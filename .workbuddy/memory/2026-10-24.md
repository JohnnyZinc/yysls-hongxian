### 已查明的三条来源
1. **燕小叽站点 COS（可用）**：`https://cos.yysls-assistant.cn/mind/<XF_KEY>.png` **对象公开可读**（200，8KB 左右），
   但**桶不允许列举**（`/?prefix=` 一律 403 AccessDenied）→ 必须知道 key 才能取。
   站点最新入口 chunk（`/assets/index-*.js`，从 `https://yysls-assistant.cn/` 首页取）里
   `keyCategorys:["mind"]` 条目只有 **41 条**，同样缺那 10 个；明晦同尘 `XF_MHTC`、大卷微身 `XF_DJWS`
   有 key 但 COS 上 **404（站点没图）**。→ 站点最新也补不齐。
2. **PC 微信本地缓存（不可用）**：`%APPDATA%\Tencent\xwechat\radium\users\<uid>\applet\`
   - `packages\<appid>\*.wxapkg` 是**加密包**（magic `V1MMWX`），其中 `wx53eacbe0d8a7a95a`
     含 `_sub-pkg_tools_` / `_sub-pkg_collect-card_` / `_sub-pkg_welfare_` 分包（高度疑似燕云官方小程序）。
   - `local\<appid>\` 只有 mmkv/store 小图/日志；日志无 URL、无中文；`applet.db` 是 SQLCipher 加密（非 sqlite 明文）。
   - webview 缓存 `radium\web\profiles\*\Cache` 里也**没有**燕云 CDN 域名（只有新浪财经/微信游戏/公众号）。
   → 不经解密或抓包，拿不到小程序里的图。
3. **官方小程序本身**：要拿图只剩 ① 抓包（PC 微信走系统代理 + mitmproxy/Fiddler 装根证书）
   ② 用户手动截图/长按保存 ③ 解密 wxapkg（逆向，不建议）。

## yysls.destiny.cool 研究：官方数据链路 + 官方素材（已落地 60 张心法图）

### 站点三层架构（研究结论，勿忘）
1. **素材层（无鉴权，静态）**：站点托管游戏解包字典 `https://yysls.destiny.cool/equip/decoded/*.json`
   共 10 个：`xinfa` / `kongfu` / `equip_icon` / `equip_name` / `equip_suit` / `equip_tiaolv` / `equip_dingyin`
   / `equip_prop` / `qishu` / `head`。图片直链在 **网易 CDN `h72.fp.ps.netease.com/file/...`**，
   **无防盗链**（带不带 Referer 都能下）。源码入口 `assets/index-*.js` 里 `rc()` 用 `Promise.all([Qn('equip/decoded/...')])`
   加载，`Qn` = 裸 fetch。
2. **账号数据层（需 token）**：`https://s3.game.163.com/7540694694f2dddc/game/regional/data?access_token=`
   （另有 `/goose` 变体；百业 `/hun/basic`、`/hun/customize/info`、`/hun/station`）。
   返回里 `passiveSlots`=已装备心法 id 数组，`xinfaInfo`=各心法重数，配 `maps.xinfa[id]` 出名字图标。
3. **token 层（需微信 PC）**：`yysls_token.exe`（站点 `/downloads/yysls_token_tool.zip`，开源
   github.com/elstp/yysls_token）**自动拉起微信 PC 里的燕云小程序** → 用户授权 → 拿 access_token。
   前提：小程序内已微信授权且绑定游戏账号。**token 几小时~1 天过期**（官方小程序限制）。

### ⚠ 踩坑：下载脚本先建文件再请求 → 404 留一堆 0 字节空壳
- `素材库/site/` 曾出现 32 个 0 字节文件，用户以为"图片打不开/被加密"。真实原因两条：
  1. `open(p,'wb')` 先建空文件再 fetch，请求失败时空壳残留 → **必须先下到内存、非空且 magic 正确才写盘**。
  2. 正则从完整 URL（`https://www.yysls.cn/pc/gw/.../27_c8ea677a.jpg`）里抠文件名后拼到站点域名
     `/assets/27_c8ea677a.jpg` → 404。**站内路径必须保留完整**（壁纸真实路径是
     `/assets/wallpaper/xx.webp`，少一层就 404）。
- 已修：删空壳 → 重写 `tools/fetch_site_assets.py`（先内存后写盘 + 保留完整相对路径 + 分类存），
  结果 33/33 成功、0 空文件。另修正 2 个扩展名与内容不符（qrcode 实为 PNG/JPEG 互换）、删 2 组重复。
- 站点素材最终：`素材库/site/` 8 个 UI 图（logo/KV/宣纸底/导航/二维码）+ `wallpaper/` 18 张站点自托管
