## 装备详情弹窗新增「调律」按钮（改已录入装备）
- 诉求：录入后不能修改，需要「调律」按钮改当前装备。
- 实现（`web/studio.js`）：
  - `state.editTarget = { kind:'equipped', slot } | { kind:'backpack', uid } | null`；非 null 即「修改模式」，null = 新录入。
  - `draftFromPiece(piece)`：已有装备 → 草稿，定音沿用原值（不回落方案默认），转律标记随行读回。
  - `actions.editPiece / saveEdit / cancelEdit`；保存原地覆盖（已穿戴保留穿戴位与 uid，背包保留 uid），不产生新件。
  - 详情弹窗动作区加「调律」按钮：已穿戴 = 调律/脱下(primary)/删除；背包 = 穿上(primary)/调律/删除。
  - 修改模式表单：标题「修改 · <部位/武器类型>」，按钮只有 保存修改 + 取消（去掉 直接穿上/添加到背包/丢弃），实时评价小标题改「（修改后）」并隐藏「建议」行。
  - **已穿戴件部位下拉 disabled**（改了就对不上穿戴位，先脱下再改）；背包件部位可改。
  - `baselineGearForEdit()`：改已穿戴件时比较基准排除它自己（否则「和自己比」恒等价）。
  - 下拉候选兜底：原词条不在当前版本候选池里时补进列表，避免静默清空。
  - Esc：修改模式下 = cancelEdit 回详情，其余弹窗 = closeModal。
- `web/studio.html` 静态资源 `?v=30 → ?v=31`。
