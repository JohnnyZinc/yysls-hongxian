# 周红线立绘 · 出图提示词（以参考图为准）

> 参考图：`周红线_1_飞哥_来自小红书网页版.jpg`
> **这张图是唯一标准**：服装、发型、挎包位置、裙摆纹样、画风、人物比例，一律照搬，一个字都不许改。
> 五张只允许变两样：**表情** 和 **右手动作**。

## 0. 怎么用（关键）

**不要**用「文生图」硬写服装 —— 写一百字也不如参考图准，还容易被脑补成别的武侠角色（加披风、加剑、改立领）。

正确做法是**图生图 / 参考图模式**：

1. 先把参考图传进去，选「参考图」或「角色一致性」。
2. 提示词 = §1 锁定段 + §2 该张的情绪段。
3. **强度/相似度调高**（豆包即梦的「参考强度」拉到 0.8 以上，GPT 直接说 "keep the character exactly"）。
4. 五张都用同一张参考图、同一组参数，只换 §2。
5. 原图是白底，出图也要白底，最后一起抠成透明 PNG。

## 1. 锁定段（每张都要整段复制）

```
严格以参考图中的角色为准，保持完全一致：

同一个女孩、同一套服装、同一种画风。十四五岁，身形瘦小，头顶两侧各扎一个丸子发髻，
红色发带打成蝴蝶结、两侧垂下长飘带；两条细辫子从耳后垂到胸前；黑色中分长发，额前碎刘海。

上身穿淡粉色格纹薄纱短外衫，白色长袖内衬，袖口有黑白细条纹；白色交领内搭；
腰间系橙色布巾打结、垂下两条橙红飘带；斜挎一只绣着花鸟的紫色小包，位置在腰侧偏前。

下身穿深蓝灰色长裙，裙面有云纹与飞鸟暗纹，裙摆边缘是回纹滚边；脚穿暗红色布鞋。

姿势：正面站立，双脚并拢略分，双手自然垂在身侧，身体正对镜头。全身像，
人物居中，脚底贴画面下边缘，头顶留一成空白。

画风：高精度 3D 角色渲染质感，柔和棚拍光，皮肤有细腻光泽，布料有真实垂坠感；
浅灰白纯色背景，无阴影、无渐变、无地面、无任何道具。

画面比例：竖版 9:16。
```

> 只改这一段的角色设定就五张一起改，别单独动某一张 —— 一动就对不上。

## 2. 五张的情绪（只替换这一段，§1 原样保留）

### ① 待机 `hongxian-idle`
```
表情与手部：嘴角轻轻上扬，眼睛自然睁着、带一点笑意，视线看向镜头；
下巴微微抬起，像刚说完"我可是摇红女侠"。双手保持自然垂在身侧。
```

### ② 思考 `hongxian-think`
```
表情与手部：眉头轻轻皱起，眼睛往斜上方看，嘴唇微微抿起；
右手抬起来、食指抵在下巴上，像在费力琢磨一件想不通的事。左手仍垂在身侧。
```

### ③ 说话 `hongxian-talk`
```
表情与手部：眼睛睁大发亮，嘴巴张开、像正说到一半、能看到一点牙齿；
右手抬到胸前、手掌摊开向外比划。整个人很有精神。左手仍垂在身侧。
```

### ④ 为难 `hongxian-unsure`
```
表情与手部：眉毛一高一低，嘴角往一边撇，眼神有点躲闪；
右手抬起来轻轻挠后脑。是"这个我拿不准"的不好意思。左手仍垂在身侧。
```

### ⑤ 生气 `hongxian-angry`
```
表情与手部：眉头皱起、眼睛瞪圆看着正前方，脸颊微微鼓起，嘴巴紧抿着；
右手握成小拳头举到胸前。是小孩子赌气喊"不然我不理你了"的生气，不是凶狠发怒。左手仍垂在身侧。
```

## 3. 负面提示词（每张都带上）

```
不要红披风、不要加剑或武器、不要加帽子或斗笠、不要改成立领、
不要改变发型（双髻、红发带、胸前两条辫子必须保留）、不要挪走挎包、
不要换裙子颜色与纹样、不要改成日系动漫大眼、不要成熟女性身材、
不要复杂背景、不要文字水印、不要第二个人物、不要手部畸形、
不要裁掉头顶或脚、不要强透视变形。
```

> 前几条是重点：这类武侠题材的模型最容易自作主张加披风、加兵器、把衣服改成劲装。

## 4. 出图后自查（五张并排看）

- [ ] 双髻的高度与形状一样，红飘带垂落角度一样
- [ ] 胸前两条辫子位置一样
- [ ] 挎包都在同侧、同一高度
- [ ] 裙子长度、裙摆展幅一样
- [ ] 人物在画面里的大小、脚底位置一样
- [ ] 画风一致（不能一张 CG、一张手绘）
- [ ] 光都一样：来自上方偏前，脸上没有硬阴影

任何一项不对就重抽那张。**别用后期缩放去凑**，脸和布料会跟着变形。

## 5. 交给程序时的规格

| 项 | 值 |
|---|---|
| 文件 | `素材库/周红线/*.png`（**白底原图就行，不用自己抠**） |
| 尺寸 | 保持参考图比例（约 9:16），建议 900 × 1600 或 1080 × 1920 |
| 主体位置 | 脚贴底边，头顶留 8%~10% 空白 |

两步，分开两支脚本（2026-11-03 起：抠图用现成工具做，脚本只管对齐）：

| 步骤 | 脚本 | 输入 → 输出 |
|---|---|---|
| ① 抠图 | 外部工具（或 `tools/cutout.py`，只适合纯白底原图） | 白底图 → 透明 PNG |
| ② 归一化 | `tools/normalize_portraits.py` | `素材库/周红线/抠图/*.png` → `web/assets/img/char/*.webp` + `manifest.json` |

归一化做的事：按 alpha 包围盒把人物统一缩放到 1180px 高 → 脚底落在同一条基线 →
按**头部中心**（顶部 10% 的中点）水平对齐 → 四张统一放进 **410×1300** 的透明画布。
宽高完全一致，换表情时连 2px 的漂移都不会有。

新增一张的流程：抠好的图丢进 `素材库/周红线/抠图/`，在 `normalize_portraits.py` 的 `JOBS` 里加一行，跑 `python tools/normalize_portraits.py`。
