# 装备品相（等阶）

品相只有四档，从高到低是 **天、地、玄、黄**。

## 判定只看结构，不看数值

一件装备属于哪一档，取决于两个计数：

- **k**＝这件装备上有几条「废词条」，也就是不在本方案配额需求里的词条；
- **m**＝这套配额的必备词条还差几条。

| 档位 | 条件 |
|---|---|
| 天 | k＝0，且 m＝0（没有废词条，必备也齐了） |
| 地 | k＝0，但 m≥1（词条都是有用的，只是还差一两条必备） |
| 玄 | k＝1（有一条废词条） |
| 黄 | k≥2（两条及以上废词条） |

数值高低、词条大小都不参与档位判断。同样的词条结构，数值高一点不会让它升档。

## 为什么地档也算好装备

地档意味着「结构完全正确，只是数量还差一点」，配上新装备或转一条律就能补齐；玄档开始有白占的槽位。所以天档和地档都值得留着，玄档看情况，黄档基本只值分解。
