# 词条配额

## 配额是什么

每个「方案」都会给出若干条配额行，每行要求某一种或某几种词条加起来达到指定条数。

- 配额统计的是**整身八件装备的所有词条**，不是单件装备。
- 一行里如果写了多种词条，它们可以**互相顶替**，凑够数量就行。
- 有的行是「任选池」，比如「小外 / 大外 任选一条」，装哪个都算。

## 缺口怎么读

对每一行算两个数：这一行现在装了几条（实装）、这一行要求几条（需要）。

- **实装 < 需要** → 缺口，这一行还缺几条；
- **实装 > 需要** → 溢出，多出来的这些条本来可以换成别的词条；
- **实装＝需要** → 这一行满了。

## 为什么不追求「零溢出」

配额是给一个可行解，不是唯一最优解。有时候多装一条有用的词条，溢出一两条别的，总伤害反而更高。所以看到溢出不用慌，先看缺口。

## 缺口和品相的关系

一件装备自己有没有废词条，决定它的品相；整身缺口决定这套还差多少。两件事要分开看：一件天档装备也可能救不了一套缺口很大的配装，一件地档装备也可能正好补上最后一条。
